# VOCO Korea

Static cycling event website, published from `main` using GitHub Pages.

https://syj133114.github.io/VOCOKOrea/

All three pages include a dark/white mode button in the header. The initial theme follows the device preference; a manual choice is saved locally and shared across pages and tabs.

To preview locally, run `python3 -m http.server 8000` and open http://localhost:8000.

Flag artwork: SVG country flags from [FlagCDN](https://flagcdn.com/), displayed in equal-size rectangles, with surrounding flags one-third the height of the Korean flag.
